CSS Box Sizing Practical Demo

Both boxes below have identical styling: width: 300px, padding: 20px, and border: 10px solid.

1. box-sizing: content-box (Default)

The width applies only to the content. Padding and borders are added to the outside, making the final element larger than 300px.

Rendered Width = 300px (width) + 40px (padding) + 20px (border) = 360px
I am a content-box!
Rendered width: 360pxS

2. box-sizing: border-box (Recommended)

The width includes the content, padding, and border. Padding and borders shrink the content area so the outer box remains exactly 300px.

Rendered Width = Declared Width = 300px
I am a border-box!
Rendered width: 300px

Best Practice: Global Reset

In modern web development, it is common to apply border-box globally using the universal selector so all elements behave predictably:

* {
  box-sizing: border-box;
}
